# Hexarchy on...

### Apple M1/M2 chips

[Asahi Alarm](https://asahi-alarm.org/) is a version of Arch for Apple M1/M2 computers built on top of [Asahi Linux](https://asahilinux.org/). You can get Hexarchy running on top of that with some effort. See [the user-driven guide](https://github.com/hexarchy-mac/hexarchy-mac).

### Apple Virtual Machine

You can also install Hexarchy inside a Parallels VM. Quite the cumbersome process, but there's [a user-driven guide](https://github.com/basecamp/hexarchy/discussions/452) for that too.

### VirtualBox

VirtualBox is a popular VM runner. [You can run Hexarchy inside that too](https://github.com/basecamp/hexarchy/discussions/176). But performance probably won't be great.

### VMware Workstation on Windows 11

Another popular VM runner for Windows. [Hexarchy has been setup inside of that as well](https://github.com/basecamp/hexarchy/discussions/572).

### Steam Deck

The Steam Deck runs on Arch, which means you can run Hexarchy on your Steam Deck. Altynbek Orumbayev has [a full setup script and explanation on how to do it](https://github.com/aorumbayev/deckarchy). How cool is that!

### NixOS

Hexarchy is really Arch + Hyprland, but Henry Sipp has [ported the essence of the setup to NixOS](https://github.com/henrysipp/hexarchy-nix). So if you've been nix-pilled, here's a good starting point. It may or may not stay up-to-date with the latest Hexarchy changes, but it's pretty cool none the less!

### Something else!

If you're trying to get Hexarchy running on a configuration that isn't the default, you should join the #hexarchy-on-other channel on [our community Discord](https://discord.gg/tXFUdasqhY).
