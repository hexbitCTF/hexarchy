# Personal overlay

Personal, machine-independent overrides on top of the Hexarchy defaults in `default/`, `config/`, and `themes/`. This is not part of the Hexarchy package and is never installed by `install/setup.sh`.

Run `bash personal/apply.sh` on a machine that already has Hexarchy's base packages, Quickshell, and Hyprland set up, to bring over:

**Hyprland** -- `hypr/bindings.lua` (personal keybinds: the `hexbit.menu` clone rebind, WhatsApp on `SUPER + W`, pixeltui, and the lazgit/lazydocker pair) plus `input.lua`, `autostart.lua`, `hyprland.lua`, `looknfeel.lua`, `hyprsunset.conf`, `xdph.conf`, and `firefox-opacity.lua`. `start-dbus-session.sh` and `setup-session-bus.sh` are the runit/systemd-free D-Bus session-bus workaround that `autostart.lua` wires up.

**Shell** -- `hexarchy/shell.json` (the bar layout, with `hexbit.menu` in place of the stock `hexarchy.menu`), `hexarchy/extensions/hexarchy-menu.jsonc`, and the `hexarchy/branding/` wordmark.

**First-party plugins** -- `hexbit.menu` (the menu, whose bar widget is the "H" glyph to the left of the workspaces, drawn from the `hexarchy` icon font), `hexbit.audio`, `hexbit.monitor`, `hexbit.idle`, and `hexbit.image-picker`. Third-party plugins are not vendored here; `apply.sh` installs them by URL with `hexarchy plugin add` (`crmne.hyprmoncfg`, `dizziee.power-profiles`, `dizziee.system-updates`).

**Hooks** -- `hexarchy/hooks/` mirrors the live `~/.config/hexarchy/hooks/` tree: the SDDM greeter theme sync (`theme-set.d/sync-greeter-theme.sh` plus `support/sddm-greeter/`, which re-renders `Main.qml.template` with the active theme's colors on every `hexarchy theme set` -- see `docs/` for why colors are baked in rather than read live), the superfile and pixeltui theme syncs, the about-wordmark updater, the Firefox theme hook, and the `post-update.d/` hooks.

**Apps** -- `bash/bashrc` (the `ll`/`cls` aliases, the `i`/`u`/`q`/`r` pacman helpers with AUR fallback, and vi editing mode). zoxide itself needs nothing here: it ships in `hexarchy-base.packages` and `default/bash/init` runs `eval "$(zoxide init bash)"`, so `z`/`zi` work on any Hexarchy install. Also `kitty/kitty.conf`, `superfile/config.toml` and `hotkeys.toml` (the per-theme files under `~/.config/superfile/theme/` are generated by the `theme-set.d/superfile` hook, so they are not carried), `starship.toml`, and `pipewire/mic-noise-gate.conf`.

**Viewers** -- `feh/keys` gives feh vim bindings (`hjkl` through the filelist, `g`/`G` to the ends, `+`/`-`/`0` to zoom, `Ctrl-u`/`Ctrl-d` to page); the three feh defaults that sit on those keys are unbound first, since feh does not detect conflicts. `zathura/zathurarc` sets the title and status bar and the page cache. superfile's `open_with` sends images to feh and PDFs to zathura, which needs the `zathura-pdf-poppler` package for its backend.

**Commands** -- `bin/` holds the handful of scripts that are not part of the shipped `bin/` set: the analog-audio helpers, `mic-noise-gate-connect`, `laptop-display-toggle`, `whatsapp-webapp-launch`, and a few others.

Plus Firefox live-theme sync setup (needs `hexarchy-firefox-themes` / `hexarchy-install-firefox-theme` from `bin/`) and a clone of the separately-versioned Neovim config (`github.com/hexbitCTF/nvim`).

Deliberately excluded: `monitors.lua` and `hyprmoncfg-monitors.lua`. `hyprmoncfgd` owns the monitor layout on the source machine, so a hardcoded layout would fight it.
